## Evidence vocabulary

- **Implemented/tested:** source and automated tests exist; no external administration implied.
- **Bounded acceptance passed:** one named topology and procedure met precommitted checks.
- **Source-backed:** supplied evidence is retained and internally consistent, but the agent did not
  directly interrogate the underlying provider/resource.
- **Consumed and closed:** valid evidence remains citable, but its candidate, suites, authority, and
  execution path cannot be reused as fresh evidence or development input.
- **Open/design only:** no implementation or acceptance claim is made.

## Claim rule

A stronger adjective than the evidence class in this table is a defect. In particular, do not replace
“bounded,” “local,” “source-backed,” or “private-CI” with “production,” “independent,” “public,”
“certified,” or “proven” unless a new accepted evidence row is added first.
